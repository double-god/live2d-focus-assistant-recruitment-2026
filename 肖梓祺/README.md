\# 学习打卡小助手



\## 项目介绍

一个用 Python 写的命令行小工具，用来记录每天的学习打卡。



\## 功能

1\. 添加打卡记录（日期 + 学习内容）

2\. 查看所有打卡记录

3\. 统计打卡天数（同一天多次打卡只算一天）

4\. 退出程序



\## 如何运行

1\. 安装 Python 3.x

2\. 在 PyCharm 里打开 `main.py`

3\. 按 Shift + F10 运行



\## 用到的知识

\- 列表、字典、集合

\- 函数定义与调用

\- 循环（while、for）

\- 输入输出（input、print）

\- 条件判断（if-elif-else）
